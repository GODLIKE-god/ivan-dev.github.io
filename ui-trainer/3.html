Практика: расстановка флажков

Перед вами семь флажков (checkbox). Задача — расставить их в соответствии с двоичным кодом, показанным ниже. Каждая цифра соответствует одному флажку слева направо.

Двоичный код:
1 0 1 0 1 0 1

Как читать код: 1 — флажок должен быть отмечен, 0 — флажок должен остаться пустым.
