Вкладки (Tabs)

Табы (вкладки) — элемент интерфейса, который позволяет переключаться между несколькими наборами контента, не покидая страницу. В каждый момент виден только один набор — остальные скрыты.

  • 🗂️ Вкладки экономят место — вместо длинной страницы показывается один блок за раз.
  • 🎯 Используйте, когда контент равнозначен и не требует сравнения бок о бок.
  • 🚫 Не используйте вкладки для последовательных шагов — для этого лучше пошаговая форма.
  • 👁️ Активная вкладка всегда визуально выделена.
  • ⌨️ Работают с клавиатуры: Tab — переход, ← / → — смена вкладки.
