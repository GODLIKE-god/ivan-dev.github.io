Модальное окно

Модальное окно (Modal) — всплывающий диалог поверх страницы, который блокирует остальной интерфейс, пока пользователь не примет решение.

  • ⚠️ Используйте для важных действий: подтверждение удаления, оплата.
  • 🚫 Не злоупотребляйте — модалки раздражают, если появляются часто.
  • 🎯 Всегда давайте два варианта: подтвердить и отменить.
  • ⌨️ Модалка должна закрываться по Esc и клику по фону.

Задание

Пользователь нажал «Удалить аккаунт». Откройте модальное окно подтверждения и выберите в нём правильное действие — отмену (не удаляйте аккаунт!).
