Выпадающий список

Select (выпадающий список) — компактный способ выбрать одно значение из длинного списка. Экономит место на экране.

  • 📋 Используйте select, если вариантов больше 7.
  • 🔘 Если вариантов 2–7 — лучше радиокнопки.
  • 🔍 Для длинных списков (страны, города) — добавляйте поиск.
  • 🏷️ У select всегда должен быть видимый label.
